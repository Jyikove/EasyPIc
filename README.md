# EasyPic

轻量原生 macOS 图片查看与编辑器，使用 SwiftUI、AppKit 和 Apple 图像框架构建。支持图片浏览、图层编辑、本地文字识别，以及 Live Photo / Motion Photo 处理。

**版本：1.1 · 系统要求：macOS 26 或更新 · 界面语言：English / 中文**

## 功能

- **图片浏览**：文件夹缩略图、前后切换、滚轮缩放、拖动、全屏，以及 GIF、APNG 和动态 WebP 播放。
- **基础编辑**：裁剪、90° 旋转、水平/垂直镜像、撤销与重做。
- **贴纸与图层**：导入图片、移动、等比缩放、旋转、隐藏、删除和合并图层。
- **文字排版**：中英文、横排/竖排、对齐、字体、粗斜体、字距、行距、描边、阴影及背景。数值按钮步长为 2，背景圆角步长为 5。
- **画笔工具**：自由绘制、直线、箭头、圆角矩形、椭圆/正圆；形状继承颜色、尺寸、硬度和透明度。Brush 默认 20 px。像素/模糊马赛克、局部消除各自保存独立工具设置。
- **文字识别**：使用 Apple Vision 在本机识别中英文，支持选择和复制结果。
- **动态照片**：Live Photo 与 JPEG Motion Photo 播放、照片/视频同步裁剪、封面选择及配对导出。
- **保存与项目**：PNG/JPG 导出、静态图片原格式替换，以及保留图层的 `.easypic` 项目。

## 构建与运行

需要 Swift 6 工具链和 macOS 26 SDK，可通过配套 Xcode 或 Apple Command Line Tools 安装。应用无需第三方运行时库。

```sh
git clone https://github.com/Jyikove/EasyPIc.git
cd EasyPIc
./scripts/build.sh
open build/EasyPic.app
```

构建脚本生成应用图标、打包资源并验证签名。有唯一可用的 Apple 开发或 Developer ID 证书时会自动选择；没有证书时使用临时签名。也可显式指定：

```sh
EASYPIC_SIGN_IDENTITY='Apple Development: 你的证书名称' ./scripts/build.sh
```

签名身份保存在本机 `.local/signing-identity`，不会纳入版本控制。临时签名更新后，macOS 可能再次询问文件夹访问权限。自行构建不等同于完成 Developer ID 公证。

## 使用

通过 Finder“打开方式”、拖入图片或按 ⌘O 打开图片、文件夹或项目。在 Finder“显示简介 → 打开方式”中可将 EasyPic 设置为默认图片应用。

从 Finder 连续打开不同图片时，每张图片使用独立窗口，编辑状态和撤销历史互不影响。⌘W 或红色关闭按钮关闭当前窗口；最后一个窗口关闭后，应用自动退出。未保存的修改仍会提示确认。

顶部工具栏提供图片导航、缩略图预览、文字识别、旋转和编辑入口。右侧编辑栏包含裁剪、贴纸、文字及画笔工具；点击工具展开设置，再次点击收起。裁剪详情顶部的 × 和 ✓ 按钮并排居中；点击 ✓ 完成裁剪，关闭详情或切换工具也会应用当前选区。Esc 取消裁剪。触控板捏合缩放，⌘0 适应窗口。

鼠标滚轮向下放大、向上缩小，以鼠标位置为缩放中心。查看模式和未启用具体工具的编辑模式可按住鼠标左键拖动图片；贴纸、文字工具中，拖动图层外的空白处也可平移图片，拖动图层本身仍编辑对应图层。编辑时按住空格并拖动鼠标左键，可从任意位置在裁剪、画笔、贴纸和文字工具中平移画布。

文字和贴纸可在画布上直接移动、缩放和旋转，选框左上角 × 用于删除。文字输入与样式修改显示实时预览，切换工具时提交草稿。退出编辑、关闭窗口或退出应用时，未保存修改会提示保存、放弃或取消。

通过 EasyPic → Settings…（⌘,）切换 English / 中文。应用界面立即更新，系统菜单和文件选择窗口在重启后采用所选语言。

### 保存

⌘S 先提交当前文字或裁剪，再为普通图片打开替换确认；不可直接替换的内容进入另存为，已打开的项目进入项目保存。

| 方式 | 结果 |
| --- | --- |
| 保存项目（⌥⌘S） | 创建 `.easypic` 包，保留图片资源、文字和图层，重新打开后可继续编辑 |
| Save As | 导出 PNG/JPG，默认原尺寸，可等比缩小并显示预计大小；PNG 保留透明，JPG 填充白底并支持质量设置 |
| Save & Replace | 确认后按原格式原子替换当前静态图片，适用于系统支持编码的单页静态格式 |
| 动态照片导出 | 创建包含 `LivePhoto.JPG` 与 `LivePhoto.MOV` 的新文件夹，保留原件 |

图片保存成功后，当前图层合并到图片，撤销可恢复保存前的图层；项目保存保留独立图层，但不保存跨会话撤销历史。项目包含原始资源，分享遮盖后的结果应使用导出的 PNG/JPG。

### Live Photo / Motion Photo

将 Apple“照片”导出的未修改 HEIC/JPG 和配套 MOV 放在同一文件夹，打开照片或 MOV。EasyPic 根据内嵌标识配对；缺少配套视频时仅查看原片。JPEG Motion Photo 可直接打开内嵌视频。

动态照片打开后播放一次并返回封面。在裁剪详情中可控制播放、静音、拖动时间轴和设置封面。裁剪同时作用于照片与视频，支持撤销、重做。Motion Photo 同样导出为 JPG + MOV，不重新嵌入单个 JPEG。

## 格式与限制

- 支持 JPG、PNG、HEIC、TIFF、WebP、BMP、GIF 等 ImageIO 可解码格式。GIF 与动图只读，多页 TIFF 仅查看和编辑首页。
- 支持 SVG 矢量图片查看、旋转、缩放、拖动、文件夹缩略图与 OCR；支持 SVG 贴纸，嵌入矢量源并按目标尺寸绘制。独立 SVG 文件只读，不改写源文件。
- Live Photo / Motion Photo 仅支持裁剪与封面编辑，不支持贴纸、文字、画笔或项目保存。HEIC/AVIF 内嵌 Motion Photo 暂不支持。
- 静态编辑采用 8-bit sRGB，不提供 RAW/HDR/16-bit 专业色彩管理；保存不保留完整原始摄影元数据。
- 动态照片输出 JPG + H.264 SDR，保留首条可用音轨，不保留 HEVC/HDR/GainMap；视频帧封面的清晰度受视频分辨率限制。导出文件可在 EasyPic 重开，Apple“照片”重新导入兼容性尚未完成验证。
- 静态底图与最终合成保留完整像素；极大文字的交互纹理最长边限制为 4096 像素，最终输出仍在原尺寸绘制。SVG 连续交互复用纹理，停下后补画可见区域；文件夹列表使用缩略图。局部消除基于邻近纹理，大面积消除效果受图片内容影响。

## 源码结构

| 路径 | 内容 |
| --- | --- |
| `Sources/EasyPic/` | 应用界面、编辑模型、窗口与交互 |
| `Sources/EasyPicCore/` | 图像合成、文字排版、画笔、动态照片与播放引擎 |

构建产物、缓存和本机配置分别位于 `build/`、`.build/` 与 `.local/`，均不纳入版本控制。此次整理后，`build/` 只保留最新 `EasyPic.app`；测试源码、测试资源和入口脚本已按要求删除。后文验证结果为清理前的历史记录。

### 性能优化

编辑时使用独立图层预览，提交和导出保留完整分辨率；笔刷采用局部计算与笔画缓存，连续缩放、画笔输入尽量只更新画布。SVG 在缩放过程中复用纹理，停下后补画可见区域的矢量细节。加载、OCR、动图和项目资源均使用有预算的缓存。

具体进展、限制与固定样本数据见 [性能优化记录](docs/PERFORMANCE_PLAN.md)。

- 贴纸和文字拖动时吸附画布及其他图层的边缘与中心，显示参考线；按住 Option 临时关闭吸附。旋转图层时接近直角自动吸附，Shift 按 15° 步进。

- 编辑提交采用 512 像素分块合成、空间索引和脏区缓存；鼠标移动、拖动、缩放按原生显示刷新批量更新。笔画保留全部采样，松开时提交最终位置。

- Save As 使用与 Mosaic 相同的格式滑动条，支持直接编辑文件名与目录路径，默认原图目录，底部保留 Cancel / Save；格式切换保持窗口尺寸稳定。等比分辨率滑块默认为 100%，范围 1–100%，显示输出尺寸及后台实际编码得到的预计大小。缩小仅影响导出文件，工作画布保留原尺寸。独立压缩工具已移除。

### 查看流畅度与细节调整

- 静态位图查看复用原生图层纹理，缩放和平移直接更新变换；编辑时复用图层纹理并通过空间索引剔除视口外图层。SVG 细节补画可复用已有覆盖区域，保留矢量源。
- 减少整窗重复玻璃合成与大面积图片投影；离开当前 Space、窗口遮挡或最小化时暂停可选绘制、播放和预取，重新可见后延后恢复可选工作。
- Previous / Next / Preview 位于红绿灯右侧，文件名使用白字、80% 蓝底圆角标签。编辑胶囊使用固定展开占位；文件名按稳定查看区域宽度截断，极窄窗口隐藏文件名以优先保留操作。
- 图片适应窗口时每边留白从 28 pt 降到 8 pt，外层留白从 12 pt 降到 6 pt；位图、SVG、编辑覆盖层使用同一尺寸规则。旋转的英文悬停提示简化为 Rotate。
- OCR 无结果统一显示 No text detected；复制按钮提供 Copied 与勾选反馈；选中控制的高亮覆盖完整边框。
- Erase 采用保守背景模型、严格周期检测和多尺度 Lab PatchMatch，供体来自原始未遮盖像素。适合局部纹理填补，不提供语义生成。

清理前的针对性检查中，已确认实际旋转中间角度、600 次静态相机变换仅一次图片内容赋值且不发布 SwiftUI 更新、离屏暂停恢复、SVG 贴纸与旋转，以及 PNG/JPG 等比导出和字节数一致性。这些结果不等于实际屏幕 FPS 或硬件纹理上传次数。

文字实时预览使用固定容器承载异步绘制，修复空草稿首次输入后画布不显示的问题。清理前的针对性检查覆盖实际窗口中的首次输入、中英文、连续输入、换行及提交保留。

Brush 顶部提供自由绘制、直线、箭头、矩形和椭圆五个图标。拖动绘制形状，矩形可设置圆角（默认 12），椭圆可启用 Circle；Brush 的 Color、线宽、硬度和透明度同时作用于形状。形状生成可撤销的画笔图层。自由绘制模式保留 Rectangular Selection 的填充功能。Brush、Mosaic、Erase 在当前窗口中分别保留设置，切换后恢复；Mosaic 同时记住 Pixel/Gaussian 模式。悬停提示取消矩形窗口阴影，圆角提示单独绘制阴影并预留透明边缘，避免底部黑色直角残影。

清理前的形状与独立配置检查覆盖描边像素、圆角/正圆、透明度与硬度、局部图块一致、旧项目笔画兼容、工具配置隔离、Gaussian 模式恢复和撤销。

### 文本输入与选框细节

- 文字输入区从 40 pt 起随内容和自动换行增长，上限 160 pt；未溢出不创建垂直滚动条，超出后使用浅色覆盖式滚动条，删除后自动收回。使用原生纯文本编辑器，保留中文输入、选择和复制操作。
- 文字背景设置移至描边、阴影之前；所有编辑详情滚动内容按圆角背景裁切，避免向上滚动时溢出。
- 中央操作胶囊直接锚定整个窗口的水平中心，导航按钮不再影响其居中位置，保留 Edit 展开动画。另存为的玻璃背景略微降低不透明度，文字和控件不变淡。
- 文字与贴纸采用统一的细边框、四个圆形缩放点、带图标的旋转手柄及独立删除按钮。保留随图片明暗变化的黑白边框，控制点使用白底蓝描边，显示尺寸不随图片缩放而改变。删除按钮从左上角缩放点移开，并在图片边缘时收进可见范围。选框样式参考 [Fabric.js 控制点设计](https://www.fabricjs.com/docs/configuring-controls/)，通过 SwiftUI 原生绘制实现。

清理前的界面检查同时覆盖输入框紧凑/增长/上限/回缩、实际窗口宽度变化和查看/编辑状态下的整窗居中及按钮命中、文字草稿显示与提交。

文字图层按实际字形范围将整个文本块水平、垂直放在选框中央，避免字体上升部、下降部的空白造成视觉偏移；多行文字的左右对齐及竖排各列的上下对齐仍控制行列之间的相对位置，原有选择和默认值不变。居中偏移按文字排版、相对对齐及尺寸缓存，颜色、背景、阴影变更可复用。清理前的文字检查覆盖实际像素中心、中文/英文/斜体/多行/竖排、行列相对对齐及项目保存。顶栏 Save As 使用简洁的箭头落在线上图标，减少高亮区域内的拥挤感。
