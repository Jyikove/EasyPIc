# EasyPic

轻量原生 macOS 图片查看与编辑器。当前版本 **0.9.0 / 统一液态玻璃界面**，要求 macOS 26 或更新。GitHub 仓库名称为 **EasyPIc**，应用名称为 **EasyPic**。

目前已完成基础查看、裁剪、旋转、镜像、PNG/JPG 导出、只读动图播放，以及 Live Photo / Motion Photo 的播放、裁剪与封面设置。现已加入静态图片贴纸、图层操作和 `.easypic` 项目保存。按照“先功能、后 UI”的顺序继续开发，文字排版、本地画笔已实现，正在优化界面与交互；AI 编辑已按用户要求移除。完整工作进度见 [PROGRESS.md](PROGRESS.md)，实测记录见 [VALIDATION.md](VALIDATION.md)。

## 运行

先按下文构建，再双击 `build/EasyPic.app`，或在项目目录执行：

```sh
open build/EasyPic.app
```

从 Finder 用 EasyPic 打开图片（可在 Finder“显示简介 → 打开方式”设为默认），或拖入图片、用 ⌘O 打开。默认仅显示图片，右侧栏收起。红绿灯同一行依次是六个图标：上一张、下一张、预览、提取文本、逆时针旋转 90°、编辑；悬停显示功能提示。编辑时前五个查看按钮禁用，图片前后导航快捷键也禁用；退出编辑后自动恢复。

“预览”在右侧显示当前文件夹的图片缩略图，点击切换，当前图片高亮；缩略图按需加载并有缓存上限。“提取文本”使用 Apple Vision 在本机识别中英文，结果可选择或一键复制；识别静态图片的完整编辑结果，动图与 Live Photo 使用封面图片。切换图片或编辑后刷新结果，关闭面板后忽略未完成的旧结果。预览、OCR 和编辑栏互斥，再次点击同一图标收起。

“编辑”使用铅笔头图标，点击后在右侧展开纵向工具栏，从上到下为：撤销、重做（取消撤销）、裁剪、水平镜像、垂直镜像、逆时针旋转、添加贴纸、添加文本、纯色画笔、马赛克画笔、消除画笔、保存并替换原图、另存为。全部只显示图标，悬停显示名称；镜像使用水平/垂直双向箭头，旋转使用单个逆时针箭头。

一级编辑按钮为正方形圆角玻璃按钮。裁剪、贴纸、文本和画笔 在工具栏右侧展开详情，面板高度贴合内容并垂直居中，超过窗口高度时滚动；重复点击工具或点击 × 收起详情。撤销、重做、镜像和旋转直接执行。裁剪默认自由比例和全图白色九宫格，拖动边角调整大小、拖动内部移动，选区外变暗；双击选区或按 Enter 应用，Esc 取消。比例按顺序竖向显示：自由比例、原图比例、1 : 1、3 : 4、4 : 3、16 : 9、9 : 16、2 : 3、3 : 2、18 : 9、9 : 18、2.39 : 1。贴纸和文字分别显示自己的图层、变换属性和一键合并按钮。大图可以滚动，触控板捏合缩放，⌘0 适应窗口。点击顶部铅笔退出编辑时，未保存的本次编辑会提示保存、不保存或取消；不保存恢复本次进入编辑时的状态，保存成功后返回查看模式，期间已有成功保存则以最近保存作为恢复点。

GIF、APNG 和动态 WebP 自动按原始帧时长循环播放，菜单栏“图片”可暂停或重播。动图只读，编辑按钮禁用，不能编辑或导出为静态图；单帧 GIF 也只读。它们仍支持缩放、滚动、OCR 和文件夹前后浏览。多页 TIFF 是静态文档，目前只查看和编辑首页，不当作动画播放。

Live Photo：将从 Apple“照片”导出的未修改 HEIC/JPG 和 MOV 放在同一文件夹，打开照片或配套 MOV。EasyPic 按内嵌标识配对，文件名相同不会自动视为一对；缺少配套 MOV 时仅可查看原片。也支持带内嵌视频的 JPEG Motion Photo，包括新版 XMP 容器和旧版 MicroVideo 偏移；HEIC/AVIF 内嵌 Motion Photo 暂未支持。

动态照片打开后播放一次，结束回到封面；点击“编辑 → 裁剪”，应用或取消裁剪后，详情中可暂停、重播、静音，拖动时间轴并点击“将当前帧设为封面”。仅提供裁剪和设置封面，支持撤销/重做；裁剪同时应用于照片和视频。

动态照片导出为新的配对文件夹，包含 `LivePhoto.JPG` 和 `LivePhoto.MOV`，不覆盖原件，可在 EasyPic 中重新打开。Motion Photo 同样导出为配对文件，不重新嵌入单个 JPG。保留首条可用音轨；输出 JPG + H.264 SDR，不保留 HEVC/HDR/GainMap。新封面取自视频帧，清晰度受视频限制。Apple“照片”重新导入的系统兼容性仍待实测。

| 操作 | 快捷键 |
| --- | --- |
| 打开图片/文件夹 | ⌘O |
| 保存可编辑项目 | ⌘S |
| 导出图片 | ⇧⌘S |
| 撤销 / 重做 | ⌘Z / ⇧⌘Z |
| 右转 / 左转 | ⌘R / ⇧⌘R |
| 开始裁剪 | ⌘K |
| 适应窗口 / 实际像素 | ⌘0 / ⌘1 |
| 上一张 / 下一张 | ← / → |
| 展开 / 退出全屏 | ⌃⌘F |

普通模式下，预览、OCR 和编辑侧栏根据实际宽度向窗口外扩展，收起时缩小总窗口，图片预览区域大小保持不变；切换二级工具或内容宽度变化时也会调整窗口。全屏模式保持屏幕尺寸，侧栏通过压缩内部预览区域展开，退出全屏后按当前侧栏宽度恢复普通窗口。Brush、Mosaic 和 Erase 的 Size 范围为 10–100 px，默认 40 px。

侧栏采用淡入淡出和轻微水平位移，工具切换交叉淡化，确认弹窗轻微缩放，选色/字体/导出/设置内容淡入，关于窗口与悬浮提示淡入淡出；原生浮窗与 Sheet 保留系统关闭过渡。动画约 0.1–0.24 秒，尊重“减少动态效果”。普通模式画布与侧栏独立定位，窗口保持原点并逐帧向右伸缩，目标是展开全程图片位置不变；手动调整窗口后按新的图片区域继续计算。此轮调整的实际效果待用户确认。

## 构建和验证

需要包含 macOS 26 SDK 和 Swift 6 工具链的 Apple Command Line Tools；也可使用配套 Xcode。应用无需第三方运行时库。首次下载源码并构建：

```sh
git clone https://github.com/Jyikove/EasyPIc.git
cd EasyPIc
./scripts/build.sh
./scripts/check.sh
```

`check.sh` 运行 41 项独立验证，检查像素结果、裁剪、历史、EXIF、透明度、PNG/JPG 编码以及动画识别、帧时长、帧合成、播放控制和文件切换，以及动态照片配对、同步裁剪、封面、音轨、导出重开和取消清理，以及贴纸透明合成、图层变换、历史和项目保存恢复。新增查看工具验证覆盖缩略图方向与尺寸、损坏路径和中英文/空白图片 OCR，可用 `.build/release/EasyPicChecks --viewer-checks` 单独运行。测试图片已包含在项目中，不需要安装 Pillow；仅重新生成动画测试图片的脚本 `make-animation-fixtures.py` 需要 Pillow。Command Line Tools 没有 XCTest，所以此项目不使用 `swift test`。

`./scripts/check-viewer.sh` 共运行 21 项验证：4 项缩略图/OCR 检查，以及 17 项编辑模型/几何/保存检查。覆盖查看器导航、面板互斥和 OCR 生命周期，以及工具展开与直接操作、变换/历史、贴纸导入、文字草稿提交、AI 保护、GIF/Live Photo 编辑限制、全部裁剪比例及边角/移动边界、实际裁剪像素和同格式原图替换。模型检查不启动应用窗口；Live Photo 样本每次生成到独立目录，避免覆盖已有文件。编译与生成的图片保存在忽略的 build 目录。OCR 使用 [Apple Vision 的文字识别请求](https://developer.apple.com/documentation/vision/vnrecognizetextrequest)。

## 界面语言

默认使用英文。通过 EasyPic → Settings…（⌘,）选择 English 或中文；选择会记住，应用自定义界面立即更新，系统菜单和文件选择窗口在重启后采用所选语言。图片内文字、OCR 结果、文件名与输入内容不作翻译。按钮悬停提示约 0.12 秒触发，查看器和一级编辑栏图标使用更大的点击区域。

## 保存图片

一级工具栏末尾提供两个保存图标。Save & Replace 提交当前文字草稿后弹出确认，确认后按完整像素合成全部图层，并保持实际格式与路径写回；编码、解码与尺寸校验通过后原子替换。保存成功后，当前图片的全部图层合并到原图，撤销可恢复保存前的图层。取消确认或写入失败不合并图层、不改写原件。该按钮仅用于系统可编码的单页静态图片；GIF/动图、多页 TIFF、Live/Motion Photo 和项目包禁用。

Save As 打开格式选择，可选 JPG 或 PNG；JPG 可调质量、透明部分填白，PNG 保留透明。成功写入新文件后，当前图片的图层同样自动合并，保留撤销。Live/Motion Photo 沿用 JPG+MOV 配对导出。直接替换沿用现有 8-bit sRGB 合成流程，不保留原始 EXIF/HDR 等完整摄影元数据。

## 贴纸与可编辑项目

打开静态图片后，点击编辑 → Sticker → Import Sticker…，或将一个或多个图片文件拖入贴纸详情面板。点击贴纸选择、拖动移动，三个角等比缩放，上方圆点旋转，左上角 × 删除。右侧数值框右对齐，左右的 −/+ 调整数值；贴纸列表支持选择和隐藏。贴纸和文本选框根据图片明暗使用黑色或白色。

贴纸和文本详情中的 Merge Layers 直接合并当前所有图层到图片，不再选择合并方式。合并保持当前可见外观，隐藏图层清除，文字变成图片；撤销可恢复全部独立图层。合并使用完整像素，并先提交正在编辑的文字草稿。

整图裁剪、旋转和镜像同步作用于全部图层。画布预览最长边最多 1600 像素，导出使用完整像素；预览与导出共用合成流程。⌘S 或“保存项目”创建 `.easypic` 包，打开面板或 Finder 可重新打开；保存项目时保留编辑图层，导出 PNG/JPG 时合成为单张图片。当前不保存跨会话撤销历史。动图及 Live/Motion Photo 不支持贴纸或项目保存。

## 文字与画笔

点击编辑 → Text 直接进入文字设置：优先编辑当前选中或最后一个文字图层，没有文字时打开空白草稿。空草稿不写入图层和撤销历史，输入文字后切换工具会提交；Add Text 用于继续添加文字。双击已有文字也可进入设置。字体通过按钮打开弹窗，保留本机经过筛选的 27 种常用字体，每项用自身字体显示 “Font” 预览。支持中文、字号、颜色、B/I、描边、阴影、背景、内边距、圆角和字距/行距；中文缺少原生样式时使用加粗/倾斜补全，西文字体通过系统字体回退显示中文。六个互斥图标选项分别使用横排左/中/右对齐、竖排上/中/下对齐。竖排逐个完整字符从上到下堆叠，字形保持正向；换行从右向左新增一列，字距调节行内间距，行距调节列间距。颜色按钮与数值输入框左右对齐；新文字的描边、阴影和背景默认透明，打开选色窗口时亮度/不透明度均从 100% 开始，仅实际选色时应用到文字；背景圆角默认 0，可直接输入，−/+ 每次调整 5。文字样式实时预览，可同时拖动、等比缩放和旋转；切换工具时提交草稿，退出编辑按保存/不保存/取消处理。预览与导出共用 Core Text 排版，旧项目的明确圆角值继续保留。

工具栏直接选择 Brush、Mosaic 或 Erase，右侧设置尺寸、硬度和透明度。马赛克支持像素块/高斯模糊、强度和矩形选区；纯色支持遮盖颜色和矩形选区。纯色笔画置于顶层；马赛克和消除处理包含全部可见贴纸、文字和笔画的合成图片，操作后图层固化，撤销可恢复原有独立图层。一笔一个撤销步骤；撤销/重做保留当前二级面板，并恢复文字编辑、裁剪或画笔模式。切换或收起工具后退出绘制。处理引擎另有透明擦除与取样克隆能力，当前简约工具栏未提供对应模式和作用范围入口。修复基于邻近纹理，不保证大面积消除质量。可编辑项目包含原始资源，不应作为安全遮盖后的分享文件；分享遮盖结果请导出 PNG/JPG。

AI 编辑功能、菜单、工具按钮、选区、CLI 调用和相关测试已移除。旧项目中的图片图层仍可正常读取，旧的提示词字段不再使用。

## 当前能力和边界

- 统一的暗色低蓝 Liquid Glass：原生窗口背景、画布边框、工具栏、详情面板、按钮、输入框、开关、滑块、字体/选色弹窗、保存确认、设置及关于窗口。样式结构见 [UI_STYLE.md](UI_STYLE.md)。
- JPG、PNG、HEIC、TIFF、WebP、BMP、GIF 等 ImageIO 可解码格式；GIF/APNG/动态 WebP 只读播放，多页 TIFF 只处理首页。
- Live Photo / JPEG Motion Photo 播放、同步裁剪、封面选择及配对导出；其他编辑禁用。
- 静态图片裁剪、90° 旋转、水平/垂直镜像、撤销/重做。
- 原像素尺寸 PNG/JPG 导出，PNG 保留透明，JPG 填白底并可调质量。
- 另存为使用新文件名；“保存并替换原图”主动覆盖当前静态图片。切图和退出前提醒未保存的修改。
- 静态编辑工作空间为 8-bit sRGB，尚不提供 RAW/HDR/16-bit 专业色彩管理。
- 静态图片可保存为 `.easypic` 项目，包含归一化原图、贴纸资源和文档 JSON；重新打开仍可编辑。Live/Motion Photo 仍需配对导出。
- 文字、擦除、克隆、局部修复和马赛克已实现。详细设计见 [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md)。

构建脚本支持固定 Apple 开发签名身份，没有可用证书时使用临时签名。临时签名更新后 macOS 可能再次询问下载文件夹权限；配置方法见 [SIGNING.md](SIGNING.md)。目前本机没有开发证书，固定证书签名尚未完成，也尚未做 Developer ID 公证或 App Store 分发。仓库不包含编译后的应用、构建缓存、签名配置或私人照片；测试图片由脚本生成。

在编辑中按 ⌘Q 或关闭窗口，未保存的修改会显示与退出编辑相同的保存提示，包括尚未提交的文字草稿。Save & Replace/Save As 成功后继续退出；Don’t Save 丢弃并退出；Cancel 或保存失败保留编辑窗口。
