# EasyPic 2.0

轻量原生 macOS 图片查看与编辑器，使用 SwiftUI、AppKit 和 Apple 图像框架构建。支持图片浏览、照片调节、独立元素编辑、本地文字与二维码识别，以及 Live Photo / Motion Photo 处理。

**版本：2.0（构建 32） · macOS 26 或更新 · English / 中文**

[下载 EasyPic 2.0](https://github.com/Jyikove/EasyPIc/releases/tag/v2.0) · [更新记录](CHANGELOG.md) · [性能方案与实施记录](docs/PERFORMANCE_PLAN.md)

发布的应用下载包适用于 Apple Silicon（arm64）Mac。

## 功能

- **图片浏览**：文件夹缩略图、前后切换、滚轮缩放、拖动、全屏；GIF、APNG 和动态 WebP 播放；SVG 矢量图片查看、旋转与缩放。
- **基础编辑**：自由或固定比例裁剪、90° 旋转、水平/垂直镜像、撤销与重做。
- **Adjust**：曝光、亮度、对比度、饱和度、高光、阴影、色温、色调和锐化。实时预览、一键重置、撤销/重做、原尺寸输出；色温和色调提供渐变色轨道，全部九项使用白色竖条滑块。
- **贴纸与元素**：导入位图或 SVG 贴纸，移动、缩放、旋转和透明度设置；独立列表支持拖动排序、选中与删除。
- **文字排版**：中英文、横排/竖排、六项对齐、字体预览、粗斜体、字距、行距、描边、阴影、背景和圆角。输入区随内容增长，多行相对对齐与文本块整体居中分别处理，保留末尾空格。
- **画笔**：自由绘制、直线、箭头、圆角矩形、椭圆/正圆；形状继承颜色、尺寸、硬度和透明度，默认线宽 20 px。Brush、Mosaic、Erase 分别保存工具设置。
- **本地识别**：Apple Vision 文字识别与二维码识别。文字可框选范围，All 模式支持连续选择，Seperate 模式逐条复制，复制成功有反馈。
- **动态照片**：Live Photo 与 JPEG Motion Photo 播放、照片/视频同步裁剪、封面选择及配对导出。
- **保存与项目**：PNG/JPG 另存为、等比分辨率压缩与预计文件大小；静态图片原格式替换；保留元素和调节参数的 `.easypic` 项目。

## 使用

通过 Finder“打开方式”、拖入图片或按 ⌘O 打开图片、文件夹或项目。连续打开不同图片时，各自使用独立窗口、编辑状态与撤销历史。最后一个窗口关闭后应用退出，未保存的修改会提示处理。

### 浏览与工具栏

- 滚轮向下放大、向上缩小，以鼠标位置为缩放中心；支持触控板捏合缩放和左键拖动画布。
- 导航按钮位于红绿灯右侧，识别、旋转和编辑胶囊按整个窗口居中。窄窗口可折叠导航；编辑模式隐藏导航和文件名。
- 编辑工具依次包含 Crop、水平/垂直镜像、Rotate、Adjust、Sticker、Text、Brush、Mosaic、Erase。Undo、Redo、Save & Replace、Save As 在顶部编辑胶囊内显示。
- 普通模式通过扩展窗口给侧栏留出空间；全屏模式在固定窗口内调整画布显示区域。工具面板自适应内容高度并垂直居中。
- EasyPic → Settings…（⌘,）可切换 English / 中文。功能图标保持一致；系统菜单与文件选择窗口在重启后采用所选语言。系统 View 与 Window 菜单合并为 View & Window。

### 元素与文字

Sticker、Text、Brush 在二级工具顶部各自显示独立元素列表，最多直接显示三条，更多条目可滚动。文字以输入内容命名，贴纸以不带后缀的文件名命名，绘制元素按 Brush、Line、Arrow、Rectangle、Ellipse 分别编号。

- 列表上方元素显示在更高层；拖动行可改变遮挡关系并实时预览。不同类型的新元素默认位于已有元素上方。
- 每行右侧 × 删除对应元素，支持撤销。删除其他元素时保留当前文字输入。
- Text 和 Sticker 仅在对应工具打开时支持画布点击选择。Brush 通过列表选择，再在画布调整大小、角度和位置；再次点击同项恢复绘制。
- 点击画布空白处取消选中并隐藏选框，保留输入内容。拖动空白处用于平移；按住空格可从任意位置平移画布。
- 拖动元素接近画布或其他元素的边缘、中心时自动吸附并显示参考线；Option 暂时关闭吸附。旋转接近直角时吸附，Shift 按 15° 步进。
- 文字对齐使用六段图标滑块，分别控制横排左/中/右与竖排上/中/下。新文字先作为草稿；结束编辑、取消选中或保存时清理空白和新建后未修改的默认文本。

Adjust 调节照片底图，贴纸与文字保留独立颜色和编辑能力。拖动使用有尺寸上限的后台预览，松手提交一次原尺寸结果；数值输入短暂防抖后提交。

Crop 可拖动边缘或选区移动。详情顶部 ✓ 完成裁剪，切换工具也会应用当前选区；Esc 取消裁剪。

### 识别

文字识别打开即显示覆盖全图、无三分线的选框，调整后识别所选范围。All 整理连续文本及换行，支持鼠标选择与复制全部；Seperate 提供逐条复制，不显示 Copy All。无结果显示 No text detected。二维码网址仅在点击 Open Link 时打开。

### 保存

| 方式 | 结果 |
| --- | --- |
| Save & Replace | 二次确认后按原格式原子替换当前静态图片，适用于系统支持编码的单页静态格式 |
| Save As | PNG/JPG 导出，支持文件名、目录、JPG 质量与 1–100% 等比分辨率，显示输出尺寸及后台编码得到的预计大小 |
| 保存项目（⌥⌘S） | 创建 `.easypic` 包，保留原始资源、独立元素和调节参数，重开可继续编辑 |
| 动态照片导出 | 创建包含 `LivePhoto.JPG` 与 `LivePhoto.MOV` 的新文件夹 |

保存前先提交当前文字、裁剪和调节。图片保存成功后合并元素，撤销可恢复保存前状态；项目保存保留元素，但不保存跨会话撤销历史。导出时缩小分辨率不改变工作画布尺寸。PNG 保留透明，JPG 填充白底。

项目包含原始资源，分享遮盖后的结果应使用导出的 PNG/JPG。

### Live Photo / Motion Photo

将 Apple“照片”导出的未修改 HEIC/JPG 和配套 MOV 放在同一文件夹，打开照片或 MOV。应用根据内嵌标识配对；缺少配套视频时仅查看原片。JPEG Motion Photo 可直接播放内嵌视频。

动态照片打开后播放一次并返回封面，可播放、静音、拖动时间轴和设置封面；照片与视频同步裁剪。导出为 JPG + MOV，不重新嵌入单个 JPEG。

## 构建

需要 Swift 6 工具链和 macOS 26 或更新的 SDK，可通过 Xcode 或 Apple Command Line Tools 安装。应用无需第三方运行时库。

```sh
git clone https://github.com/Jyikove/EasyPIc.git
cd EasyPIc
./scripts/build.sh
open build/EasyPic.app
```

脚本生成图标、打包资源并验证签名。有唯一可用的 Apple 开发或 Developer ID 证书时自动选择；没有证书时使用临时签名，也可显式指定：

```sh
EASYPIC_SIGN_IDENTITY='Apple Development: 你的证书名称' ./scripts/build.sh
```

签名身份可保存在本机 `.local/signing-identity`，不会纳入版本控制。临时签名更新后，macOS 可能再次询问文件夹访问权限；自行构建不等同于 Developer ID 公证。

## 格式与限制

- 支持 JPG、PNG、HEIC、TIFF、WebP、BMP、GIF 等 ImageIO 可解码格式。GIF 与其他动图只读；多页 TIFF 仅查看和编辑首页。
- 独立 SVG 只读，支持查看、旋转、缩放、文件夹缩略图与 OCR。SVG 贴纸保留矢量源，按目标尺寸绘制。
- Live Photo / Motion Photo 仅支持裁剪与封面编辑，不支持其他编辑工具或项目保存。HEIC/AVIF 内嵌 Motion Photo 暂不支持。
- 静态编辑使用 8-bit sRGB，不提供 RAW/HDR/16-bit 专业色彩管理，保存不保留完整原始摄影元数据。
- 动态照片输出 JPG + H.264 SDR，保留首条可用音轨；不保留 HEVC/HDR/GainMap。视频帧封面清晰度受视频分辨率限制；Apple“照片”重新导入兼容性尚未完成验证。
- 极大文字的交互纹理最长边限制为 4096 px，最终输出仍在原尺寸绘制。SVG 连续交互复用纹理，停止后补绘可见区域。Erase 适合局部纹理填补，不提供语义生成。
