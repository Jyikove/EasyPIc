# EasyPic

轻量原生 macOS 图片查看与编辑器。当前版本 **0.8.0 / 两级编辑工具栏**，要求 macOS 26 或更新。GitHub 仓库名称为 **EasyPIc**，应用名称为 **EasyPic**。

目前已完成基础查看、裁剪、旋转、镜像、PNG/JPG 导出、只读动图播放，以及 Live Photo / Motion Photo 的播放、裁剪与封面设置。现已加入静态图片贴纸、图层操作和 `.easypic` 项目保存。按照“先功能、后 UI”的顺序继续开发，文字排版、本地画笔和 AI 调用入口已实现；真实 AI 生成与原生窗口交互仍待验收。完整工作进度见 [PROGRESS.md](PROGRESS.md)，实测记录见 [VALIDATION.md](VALIDATION.md)。

## 运行

先按下文构建，再双击 `build/EasyPic.app`，或在项目目录执行：

```sh
open build/EasyPic.app
```

从 Finder 用 EasyPic 打开图片（可在 Finder“显示简介 → 打开方式”设为默认），或拖入图片、用 ⌘O 打开。默认仅显示图片，右侧栏收起。红绿灯同一行依次是六个图标：上一张、下一张、预览、提取文本、逆时针旋转 90°、编辑；悬停显示功能提示。

“预览”在右侧显示当前文件夹的图片缩略图，点击切换，当前图片高亮；缩略图按需加载并有缓存上限。“提取文本”使用 Apple Vision 在本机识别中英文，结果可选择或一键复制；识别静态图片的完整编辑结果，动图与 Live Photo 使用封面图片。切换图片或编辑后刷新结果，关闭面板后忽略未完成的旧结果。预览、OCR 和编辑栏互斥，再次点击同一图标收起。

“编辑”使用铅笔头图标，点击后在右侧展开纵向工具栏，从上到下为：撤销、重做（取消撤销）、裁剪、水平镜像、垂直镜像、逆时针旋转、添加贴纸、添加文本、纯色画笔、马赛克画笔、消除画笔、AI 编辑。全部只显示图标，悬停显示名称；镜像使用水平/垂直双向箭头，旋转使用单个逆时针箭头。

点击工具后，在工具栏右侧展开对应详情；重复点击当前工具或点击详情的 × 收起详情，工具栏仍保留。撤销、重做、镜像和旋转直接执行，裁剪在画布拖出选区后应用；取消用 Esc。切换工具会退出原来的裁剪/画笔模式。贴纸和文字详情保留图层、变换属性与合并；保存项目和导出位于详情底部，也支持快捷键。大图可以滚动，触控板捏合可缩放，⌘0 适应窗口。查看界面不显示文件名、品牌标语或底部状态栏，仍可用左右方向键浏览。

GIF、APNG 和动态 WebP 自动按原始帧时长循环播放，菜单栏“图片”可暂停或重播。动图只读，编辑按钮禁用，不能编辑或导出为静态图；单帧 GIF 也只读。它们仍支持缩放、滚动、OCR 和文件夹前后浏览。多页 TIFF 是静态文档，目前只查看和编辑首页，不当作动画播放。

Live Photo：将从 Apple“照片”导出的未修改 HEIC/JPG 和 MOV 放在同一文件夹，打开照片或配套 MOV。EasyPic 按内嵌标识配对，文件名相同不会自动视为一对；缺少配套 MOV 时仅可查看原片。也支持带内嵌视频的 JPEG Motion Photo，包括新版 XMP 容器和旧版 MicroVideo 偏移；HEIC/AVIF 内嵌 Motion Photo 暂未支持。

动态照片打开后播放一次，结束回到封面；点击“编辑 → 裁剪”，应用或取消裁剪后，详情中可暂停、重播、静音，拖动时间轴并点击“将当前帧设为封面”。仅提供裁剪和设置封面，支持撤销/重做；裁剪同时应用于照片和视频。

动态照片导出为新的配对文件夹，包含 `LivePhoto.JPG` 和 `LivePhoto.MOV`，不覆盖原件，可在 EasyPic 中重新打开。Motion Photo 同样导出为配对文件，不重新嵌入单个 JPG。保留首条可用音轨；输出 JPG + H.264 SDR，不保留 HEVC/HDR/GainMap。新封面取自视频帧，清晰度受视频限制。Apple“照片”重新导入的系统兼容性仍待实测。

| --- | --- |
| 打开图片/文件夹 | ⌘O |
| 保存可编辑项目 | ⌘S |

## 构建和验证

需要包含 macOS 26 SDK 和 Swift 6 工具链的 Apple Command Line Tools；也可使用配套 Xcode。应用无需第三方运行时库。首次下载源码并构建：

```sh
git clone https://github.com/Jyikove/EasyPIc.git
cd EasyPIc
./scripts/build.sh
./scripts/check.sh
```

`check.sh` 运行 41 项独立验证，检查像素结果、裁剪、历史、EXIF、透明度、PNG/JPG 编码以及动画识别、帧时长、帧合成、播放控制和文件切换，以及动态照片配对、同步裁剪、封面、音轨、导出重开和取消清理，以及贴纸透明合成、图层变换、历史和项目保存恢复。新增查看工具验证覆盖缩略图方向与尺寸、损坏路径和中英文/空白图片 OCR，可用 `.build/release/EasyPicChecks --viewer-checks` 单独运行。测试图片已包含在项目中，不需要安装 Pillow；仅重新生成动画测试图片的脚本 `make-animation-fixtures.py` 需要 Pillow。Command Line Tools 没有 XCTest，所以此项目不使用 `swift test`。

`./scripts/check-viewer.sh` 共运行 14 项验证：4 项缩略图/OCR 检查，以及 10 项实际 EditorModel 检查。覆盖查看器导航、面板互斥和 OCR 生命周期，以及两级工具展开、变换/历史、贴纸导入、文字草稿提交、AI 保护和 GIF/Live Photo 编辑限制。模型检查不启动应用窗口；Live Photo 样本每次生成到独立目录，避免覆盖已有文件。编译与生成的图片保存在忽略的 build 目录。OCR 使用 [Apple Vision 的文字识别请求](https://developer.apple.com/documentation/vision/vnrecognizetextrequest)。

## 贴纸与可编辑项目

打开静态图片后，点击“编辑 → 添加贴纸 → 导入图片贴纸…”导入透明 PNG 或其他静态图片。点击贴纸选择，拖动移动，其余三个角等比缩放，上方圆点旋转，左上角 × 按钮删除贴纸；右侧输入精确位置、尺寸、角度与透明度，按回车确认。图层列表从上到下显示前景到背景，支持置顶、置底、复制、删除与隐藏。每次拖动或属性修改都可撤销。

贴纸和文本详情中的“合并图层”提供向下合并和合并可见图层。选中最底层时，向下操作显示为“与原图合并”；其他位置合并到紧邻的可见下层。“合并可见图层”将可见的贴纸、文字和笔画合成一个图片图层，保留隐藏层与原图。合并使用完整像素，文字会变成图片，撤销可恢复原来的独立图层；保存项目后可继续移动和调整合并结果。

整图裁剪、旋转和镜像同步作用于全部图层。画布预览最长边最多 1600 像素，导出使用完整像素；预览与导出共用合成流程。⌘S 或“保存项目”创建 `.easypic` 包，打开面板或 Finder 可重新打开；保存项目时保留编辑图层，导出 PNG/JPG 时合成为单张图片。当前不保存跨会话撤销历史。动图及 Live/Motion Photo 不支持贴纸或项目保存。

## 文字、画笔和 AI

点击“编辑 → 添加文本”，再点击详情中的“添加文本”创建文字并展开设置；双击画布上的已有文字或点击“编辑文字…”也可打开右侧文字详情。支持本机字体与系统字体面板、字号、颜色、真实粗体/斜体、描边、阴影、透明背景、内边距和圆角、字距/行距、横排/竖排与对齐。缺少所选字形时显示提示。文字可以在设置样式时拖动、等比缩放和旋转，重新打开项目仍可编辑。详情实时预览；应用文字、切换工具或收起编辑栏时将有效草稿合为一个撤销步骤，“取消修改”恢复进入编辑前的内容。预览与导出共用 Core Text 排版。背景提供“圆角背景”开关，默认半径为 12 px，可用滑杆或数值调整，并可恢复默认值；关闭开关或设为 0 使用直角。圆角随文字缩放并保存到项目，旧项目的已有圆角值保持不变。

工具栏直接选择纯色、马赛克或消除画笔，右侧设置直径、硬度和透明度。马赛克支持像素块/高斯模糊、强度和矩形选区；纯色支持遮盖颜色和矩形选区。纯色笔画置于顶层，马赛克和消除作用于原图并保留文字与贴纸。一笔一个撤销步骤；切换或收起工具后退出绘制。处理引擎另有透明擦除与取样克隆能力，当前简约工具栏未提供对应模式和作用范围入口。修复基于邻近纹理，不保证大面积消除质量。可编辑项目包含原始资源，不应作为安全遮盖后的分享文件；分享遮盖结果请导出 PNG/JPG。

点击工具栏的“AI 编辑”在右侧展开设置，打开工具不会自动调用 Codex。支持 CLI 路径选择与检测、提示词、参考图、矩形选区、进度、取消、超时及原图对比。使用独立任务目录和 `workspace-write`，复用本机 CLI 的模型/provider 与登录，不读取令牌。结果文件通过路径、格式与尺寸校验后才能应用；应用为新图层，可撤销，项目保存提示词。局部编辑仅合成选区内容，选区蒙版是参考，不能保证模型执行严格蒙版编辑。图片与提示词会发送到配置的云端服务。收起详情保留未应用的结果，打开另一张图片后清空旧结果；运行任务期间禁止切换图片或进行其他编辑。

当前真实 CLI 验收：参考图任务返回“内置图片生成工具不可用”，选区任务超时，尚无真实成功生成记录。不会把文字回复或退出码 0 当作成功，也不切换到单独付费 API。成功任务资料位于用户 Application Support/EasyPic/AIJobs，失败和取消清理任务输入。

## 当前能力和边界

- 原生 Liquid Glass 控件和面板、系统透材质窗口背景、简洁中性图片画布。
- JPG、PNG、HEIC、TIFF、WebP、BMP、GIF 等 ImageIO 可解码格式；GIF/APNG/动态 WebP 只读播放，多页 TIFF 只处理首页。
- Live Photo / JPEG Motion Photo 播放、同步裁剪、封面选择及配对导出；其他编辑禁用。
- 静态图片裁剪、90° 旋转、水平/垂直镜像、撤销/重做。
- 原像素尺寸 PNG/JPG 导出，PNG 保留透明，JPG 填白底并可调质量。
- 原图保留，导出使用新文件名；切图和退出前提醒未导出的修改。
- 静态编辑工作空间为 8-bit sRGB，尚不提供 RAW/HDR/16-bit 专业色彩管理。
- 静态图片可保存为 `.easypic` 项目，包含归一化原图、贴纸资源和文档 JSON；重新打开仍可编辑。Live/Motion Photo 仍需配对导出。
- 文字、擦除、克隆、局部修复和马赛克已实现；AI 接入完成，但当前 CLI 环境未通过真实生成验收。详细设计见 [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md)。

构建脚本使用本机临时签名，方便本机运行，尚未做 Developer ID 公证或 App Store 分发。仓库不包含编译后的应用、构建缓存或私人照片；测试图片由脚本生成。
